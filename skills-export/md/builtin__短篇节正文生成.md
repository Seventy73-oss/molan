短篇按节追加正文（800~1500字/节·节末留钩）

## 提示词模板

【节正文·官方默认】按全书蓝图写【第 N 节】正文，追加进单文本全文。
交付形态：
- **节头**：输出首行必须是 `N.`（节号 + 半角句点，独占一行），其后直接跟该节正文。
绝不写「第N节 / 第N章」标题，禁（上）（下），除节头外不要任何头部或分节标记。
- **只输出节头 + 正文**：不要任何元数据 JSON，不要解释说明。
写法要求：
- **每节四件事**（缺一件就是废节）：
① 一个变化——新信息 / 关系位移 / 危机 / 伏笔回收，至少其一，不许纯聊天纯回忆；
② 一个呼吸点——生活化吐槽或细节幽默（沉重题材换成一个温柔瞬间），防压力积压；
③ 一次关系位移——两人的距离比节首更近或更远（误会加深也算位移）；
④ 节末钩子——停在新发现 / 艰难选择 / 身份破绽上。
- **篇幅**：以当轮【篇幅要求】指令为准（缺省 800~1500 字、硬上限 2000；配置弹窗「字数」档可调到 600~800 或 1500~2000）。
- **视角**：第一人称「我」（蓝图 / 设定另有约定除外）。
- **手机屏短段**：1~3 句一段，段间空行。
- **密度**：每 600~800 字至少一个小钩子 / 转折 / 情绪点。
- **反差靠行为**：对方的在意用动作、停顿、提前安排好的小事表现，禁形容词堆砌；主角自嘲不自轻，能力用选择和行动表现，不自我宣称。
- **伏笔纪律**：上下文给了「本节须埋 / 须收」清单时照单执行；终局证据严禁临场发明。
- **禁忌**：降智误会（听见半句话就跑）、身份碾压式甜宠、配角只负责夸主角、作者替人物讲道理、大段抒情、「她不知道的是」式生硬转场。
- **付费墙卡点节**：若本节是蓝图里 `paywall` 指定的卡点节，收在全书最狠的悬念上，宁可戛然而止。
- **第 1 节承接导语**：上下文会给导语定稿原文，开头直接原样承接它往下写，不复读导语、不另写引子。
