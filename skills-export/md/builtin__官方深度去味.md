## 提示词模板

【专业去 AI 味 · 深度】目标：让文字读起来是「真人作家在讲故事」而非「AI 在输出信息」。
铁律：只改「怎么说」不改「说什么」——情节 / 人设 / 设定 / 时间线 / 叙事视角一律不动，不新增原文没有的内容；贴住本书既有的题材与文风（古风该雅则雅、文学该凝练则凝练），只清 AI 腔 / 翻译腔 / 总结腔 / 书面腔，**绝不为「口语化」把本书语体洗白**；对白按对白的口吻去、描写按描写的笔触去。
一、去泛化：概述换成具体动作与细节，情绪外化到身体 / 动作 / 环境、不直接命名情绪（不写「他很紧张」，写「他的手在抖」）；连续排比 / 对仗最多留一处、其余打散；对话标签（说道 / 问道）多删或换成动作，靠上下文分清谁在说。
二、去书面腔：「不是A而是B」直接写 B，「不仅…而且」「与其说…不如说」一并拆；删公式化框架「首先 / 其次 / 最后」「随着…的发展」「在…的背景下」；连接与总结词删或换隐性衔接（与此同时 / 然而 / 因此 / 此外 / 综上所述 / 总而言之 / 值得一提的是 / 换句话说）；形容词一处不超两个、同一比喻 / 句式一段内不复；不用被动腔与上帝视角泛论（「人们往往会…」），指明是谁、给具体的人和事。
三、回自然：长短句交错、段落参差，情绪高点或转折用极短句独立成段；结尾用一个动作或画面收住，禁止一句话升华总结（如「这一刻，他终于明白了什么是绝望」）；允许一点不完美与留白，别面面俱到。
四、禁用词（本书文风允许前提下清除或替换）：仿佛 / 犹如 / 宛若、一丝 / 一抹 / 些许 / 几分 / 隐约、深吸一口气 / 缓缓 / 不禁 / 微微 / 轻轻 / 淡淡、眼中闪过 / 嘴角勾起 / 眉头微皱 / 瞳孔微缩、心中一动 / 心头一震 / 心中暗道 / 涌起一股 / 不由得、不容置疑 / 显而易见 / 毫无疑问、无形的压力 / 说不出的 / 莫名的 / 下一秒 / 空气仿佛凝固。
改完通读一遍：仍像 AI 在「输出信息」而非真人在讲故事，就再收一遍。
