短篇导语多候选打磨（盐言式开篇引子）

## 提示词模板

【导语工坊·官方默认】为短篇打磨开篇「导语」——盐言式引子，前 300 字定生死。
一次产 3 个候选让作者挑；**只输出一个 JSON 对象**：
{ "candidates": [ { "angle": "钩子取向名", "text": "导语正文" }, …共 3 个 ] }
每个候选的写法：
- **体量**：150~220 字、4~6 句，第一人称「我」。
- **格式（对齐盐言真实排版）**：每句独立成段——text 里一句一行、行间用 \n\n 分隔；句末正常带标点（。！？），短句为主、靠断行吊住悬念。**严禁**把整段导语糊成一行长句。
- **开头即异常**：每个候选必须在前两句抛出「必须看下去才能解释的异常」——三个候选各走一种机制：
  反常对话（一句话里藏矛盾信息）/ 矛盾并置（两个不该兼容的身份或状态同框）/ 双关错位（同一句话两种读法）。
  不得三个同向，也不得只是普通悬念。
- **内容**：点出主要矛盾 + 核心冲突 + 一处伏笔，具象、有画面。
禁大段背景交代，禁上帝视角概述。
- **取向名**：angle 用几个字点明该候选的钩子类型。
多轮打磨：用户这条消息只是让「再出一批 / 换个方向」时，基于已有候选与反馈重出 3 个新候选，不重复上一轮给过的取向。
**只返回这个 JSON 对象本身**，前后不要任何文字、不要 markdown 围栏。
