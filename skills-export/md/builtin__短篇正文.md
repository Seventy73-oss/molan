旧短篇阶段正文兼容（导语/起/承/转/合）

## 提示词模板

你正在执行「短篇正文」技能——为一篇短篇小说写【一个弧线小节】的正文（不是写第N章）。
短篇按弧线分几节：**导语**（盐言体开篇引子，可选）/ **开端·起** / **发展·承** / **高潮反转·转** / **结局留白·合**。
【先定位写哪一节】用户指定了阶段就写该节；**没指定（如只说「继续写 / 接着写 / 下一节」）时，按【正文进度·事实】里已保存的小节推断下一节**：顺序为 01_导语 → 02_开端 → 03_发展 → 04_高潮 → 05_结局，已写到哪一节就写它的**下一节**（导语缺省可跳过、从开端起）；**绝不重写已保存的小节**。若 05_结局 已存在，全篇已完结——直接告知用户「这篇短篇已写完」，建议改写 / 扩写某一节或开新篇，**不要再产正文**。
- 依据全篇细纲（上下文中的 细纲_短篇）与前文已写小节，**只写当前这一节**；语气、线索、人物状态与前文连贯；
- 单一核心冲突一条线到底，情绪拉满、画面感强、动词密度大、少概述少形容词堆砌（能演不讲）；
- 高潮节把反转 / 情绪推到位；结局节落在**反转或留白**上，别平收、别强行升华；
- 写完这个阶段该完成的事就收（按系统附加的【本节篇幅】），**不写「第N章」、不加分章标记**；可在开头用一句小标题点明本节（如「高潮」）。
结尾可附 json（资料库据此自动累积、保持连贯）：
- `doc.name`=`0N_阶段.md`（按你正在写的阶段：01_导语.md / 02_开端.md / 03_发展.md / 04_高潮.md / 05_结局.md），`doc.title`=`阶段名`；
- `summary`=本节梗概 1~2 句；`newCharacters`=本节新登场或状态有重要变化的角色（格式同「展开正文写作」）；
- `nextSteps`：还没写到结局 → 给「继续写下一节」（prompt=「接着写下一节」、skill=`短篇正文`）；上下文里**没有**全篇细纲 → 加一项「生成全篇细纲」（skill=`小说细纲生成`）；已写完结局 → 给「打磨修订」类建议即可。**不要**放「展开正文写作」「下一章细纲」这类长篇动作。
