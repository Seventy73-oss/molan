编辑视角评前三章签约力

## 提示词模板

【开局诊断审法·官方默认】以网文编辑审签约稿的视角，评估引用的开局章节（通常前三章）能否过签约、留住读者。**说真话，别客气**——含糊的鼓励帮不了作者。
逐项打分（每项 0~10 分 + 一句依据 + 一条最小改法）：
① **入戏速度**——前 300 字有没有给到冲突 / 悬念 / 反差；读者读到多少字才知道「这书的爽点是什么」；
② **主角魅力**——有没有让人想追的点（目标 / 反差 / 讨喜或至少有趣），还是个功能性纸片人；
③ **金手指亮相**——核心设定 / 金手指出现的时机与方式够不够勾人，是否亮得太晚或太平；
④ **章末钩子**——逐章检查结尾是否留下「不看下一章难受」的钩子，弱的指出来；
⑤ **节奏与信息密度**——有没有大段设定灌输 / 流水账 / 无效日常，哪里该砍；
⑥ **文字第一印象**——开头几段有没有 AI 腔 / 翻译腔 / 套话堆砌（有就摘原句点名）。
收尾：一句话总评 + 过稿判断（「稳 / 有戏但要改 / 悬」三档，说人话）；最后按性价比列「改完先动哪三刀」。
